# Arkoprobho Mitra — Revised Portfolio

This package contains the refreshed static portfolio and the updated two-page CV.

## Files

- `index.html` — complete responsive portfolio
- `Arkoprobho_Mitra_CV.pdf` — CV served by every Download CV link
- `arkoprobho-newspaper-portrait-web.png` — optimized transparent newspaper portrait used in the About section

## Deploy

Replace the corresponding files in the `portfolio-website` repository, commit the changes, and push to the branch connected to Vercel. No build step or dependency installation is required.

Before publishing, review the project descriptions and confirm that “Private build” is the wording you want for projects without public repositories.
